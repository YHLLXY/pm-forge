## 结论与口径说明

1. **GitHub 提示的"4 个"是 advisory 计数口径**（postcss 一条依赖挂 4 条 advisory，聚合为 1 高 1 中两个 vulnerability）；实测审计口径：site 0 + toolkit 2。
2. **受影响依赖链**：next 15.5.26 → 内嵌 compiled postcss ≤8.5.22。postcss 是 next 的**编译内置依赖**，package.json overrides 无法覆盖，audit 明示修复版本 = **next@16.3.8（破坏性大版本）**，且 15.x 线无修复计划（受影响范围覆盖至 16.3.0-preview）。
3. **缓解论证（维持 ISSUES #13 原判）**：四条 advisory 的攻击面全部要求**攻击者可控的 CSS 输入**（stringify 输出注入 / sourceMappingURL 注释），toolkit 的 CSS 全部自有、无用户 CSS 输入通道，实际可利用性低。
4. **严禁 `npm audit fix --force`**：会把 next 顶到 16 大版本，必须走专项任务卡。
