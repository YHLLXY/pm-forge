## 二、发现与处置明细

### 已当场修复（3 项）

**F1 · RSS 自动发现链接尾斜杠（中）**
- 现象：每页 `<head>` 里 `href="https://yuhailinlxy.com/rss.xml/"` 带尾斜杠——`rss.xml` 是文件不是目录，静态托管下该地址 404，RSS 订阅器拿不到源。
- 根因：上游 `Layout.astro` 用 `getRelativeLocaleUrl(locale, "rss.xml")`，astro:i18n 一律追加尾斜杠。
- 修复：Layout 内改为字面量 `/rss.xml`（单语言站无需 locale 路由）；`dist/index.html` 复验 `https://yuhailinlxy.com/rss.xml` ✓。

**F2 · Quarto 报告引用 jsdelivr CDN（中，国内可访问性维度）**
- 现象：`case1-userbehavior.html` 内嵌 `<script src="https://cdn.jsdelivr.net/npm/jquery@3.5.1…">` 与 requirejs 两处——jsdelivr 国内时好时坏，且违背"零外部资源"硬约束。
- 修复：jquery 3.5.1 / requirejs 2.3.6 经 npmmirror 下载入库（`analysis/assets/local-libs/`，约 176KB）；新增持久化补丁脚本 **`analysis/scripts/patch_report_cdn.py`**（quarto render 后重跑即可，README 已注明流程）；canonical 与 site 两份报告副本均已打补丁，dist 复验外部资源加载数 = 0 ✓。
- 注：integrity/crossorigin 属性随内联化一并移除（同源文件无需 SRI）。

**F3 · 死代码（低）**
- `src/utils/toTransitionName.ts`、`src/components/ResponsiveTable.astro` 零引用（Card 泛化与 posts 页删除后遗留）→ 删除；Main/Breadcrumb 经核实被 about.astro 使用，保留。

### 登记延后（4 项）

**D1 · toolkit：Next.js 内嵌 postcss 漏洞 ×2（1 高 1 中）→ ISSUES #13**
- `postcss <=8.5.22`（next 的传递依赖，构建期使用）：CSS stringify XSS、sourceMappingURL 任意文件读取系列。攻击面需要**攻击者可控的 CSS 输入**——toolkit 的 CSS 全部自有，无可控输入面，实际可利用性低。
- 官方修复需升 **next@16.3.6（破坏性大版本）**：不与本次检查混做，列专项（须全量回归 52 vitest + 3 e2e + 线上冒烟）。

**D2 · npmmirror 不提供 npm audit 接口（环境限制）**
- `npm audit` 在镜像源下报 `[NOT_IMPLEMENTED]`；此后审计一律加 `--registry=https://registry.npmjs.org`（已写入方法论文档命令）。

**D3 · git 历史含上游 demo 图片约 4MB**
- T1 复制 AstroPaper 时带入的博文配图，T2 已删文件但历史留存。不改写已推送历史（风险 > 收益），仅记录。

**D4 · check-links.mjs 局限性**
- 相对路径引用（非 `/` 开头）被跳过不查；当前 Astro 产物全部根相对，无实际影响。若未来引入相对路径写法需补充。
