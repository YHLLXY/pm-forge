## 2 被工具抓出来的问题（我自己没看见）

### 2.1 门禁假绿：改了第 6 格，旧门禁照样通过

改完第 6 格后 `npm run build` 全绿，日志写着「最近更新「2026年10月7日」与内容集合一致」——但我已经把那一格改成 `10.27` 了。

原因：`check-home-metrics.mjs` 只做 `html.includes("2026年10月7日")`，而首页「最新分析」卡片的日期正好也是这一天。**断言在别处命中，面板坏了也不会红。**

改法：面板第 6 格加 `data-evidence-updated="YYYY-MM-DD"`，门禁直接核对这个属性 + 核对渲染出的 `MM.DD`。发版日单独放 `src/data/release.ts`，门禁用正则独立读（保持"两份实现"的独立性）。

### 2.2 SVG 旋转原点：三条环各自绕角落转

第一版把三个 `<circle>` 放进同一个 SVG 直接转。实测环心偏移容器中心 **-33 / +23 / -22 px**（`getBoundingClientRect` 读的是旋转后包围盒，所以半径也虚高到 243/176/117）。原因是 SVG 元素的 `transform-origin` 默认落在 viewBox 的原点，不是圆心。

改法：每条环各包一个 HTML `<div>`，转容器的中心。改完三个环 `dx=dy=0`，节点半径 218/161/109 与环半径一致。

### 2.3 移动端横向滚动

旋转的 `.crotor` 是 `inset:0` 的方框，一转起来四角超出容器：`document.scrollWidth 417 > innerWidth 390`。给容器加 `overflow: hidden` 后回到 375。

### 2.4 `check-tokens` 逮到我自己写的注释

我在 CSS 注释里写了「第一版用 border(#e6e2db)」，门禁按"裸 hex"报错。修法是改注释措辞，**不是**加白名单——门禁对注释也生效是有意的。

| `qq-qr.png` | 51,862 B | `https://qm.qq.com/q/mQ1Z3jmgRc` |

## 4 动效与无障碍

- 公转用「外层自转 + 内层反向自转」，相位差用负 `animation-delay`；不用 `offset-path: circle()`（Safari 支持面不稳，面试官可能用 Mac）。
- 悬停/聚焦整套暂停，否则节点一直在跑，点不准。
- reduce 下停转，并用 `--phase` 把四个节点钉在四个方位（否则会叠在 12 点）。`check-reduce-motion.mjs` 已扩到断言这两点。
- 弹层是原生 `<dialog>`：自带焦点陷阱与 Esc，点遮罩关闭，关闭后焦点回到触发按钮。

## 8 线上复测（部署后）

### 8.1 点卡片 / 点返回（`docs/tools/measure-nav.mjs`）

| 阶段 | 点卡片 click→swap | 点返回 click→swap |
|---|---|---|
| 改前（10-27 23:52） | 581 / 366 / 409 ms | 1166 / 290 / 600 ms |
| 只加 viewport 预取（10-28 00:50） | 798 / 334 / 719 ms | 1419 / 386 / 406 ms |
| **再加 HTML 缓存头（01:00）** | **30 / 26 / 44 ms** | 1472（冷启动）/ 28 / 85 ms |
| **返回按钮也预取（01:10）** | 37 / 31 ms | 1569（冷启动）/ **36 ms** |

中间那行为什么没变快：预取请求确实发出去了（`initiatorType: link`，TTFB 573–717ms），
但 Vercel 给 HTML 的默认头是 `public, max-age=0, must-revalidate`，Router 真正取页面时仍要重新校验一趟。
改成 `max-age=60, stale-while-revalidate=86400`（只作用于无扩展名的 HTML 路由）后，预取那份才被真正复用。

### 8.2 为什么 TTFB 是 0.9–1.1 秒

| 资源 | TTFB | 缓存头 |
|---|---|---|
| `/case-studies/`（HTML） | 1.119 s | `x-vercel-cache: HIT`、`Age: 2` |
| `/`（HTML） | 0.912 s | 同上 |
| `/_astro/Footer.*.css` | 0.767 s | `max-age=31536000, immutable` |

连强缓存的 CSS 都要 0.77s，说明这段时间是**链路往返**（国内 → Vercel 海外节点），不是边缘未命中。
客户端能做的是「别让读者等这一趟」：预取 + 60 秒浏览器缓存 + 进度条；再往前就是国内 CDN / ICP，属于另一个决定。
