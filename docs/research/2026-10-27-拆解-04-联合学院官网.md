## 2. 骨架与模块语法

```
header.header          100px   蓝→绿渐变，sticky top:0，阴影
section.banner         750px   揭牌仪式大图（2.1 MB JPG）+ 标题压字 + 左右箭头 + 指示点
div.container        2,924px
  ├ section.content-module.news-feature   1,059px   综合新闻（左图左文 + 右侧列表）
  ├ section.content-module                1,059px   通知公告（紫色日期徽章列表）
  ├ section.content-module                883px     信息公开（日期徽章 + 标题 + 摘要）
  ├ section.content-module.card-module    883px     招生资讯（3 张卡：招生简章 / 云游校园 / 常见问题）
  └ section.content-module.card-module    883px     学生支持（3 张卡：发展指导 / 师生互动 / 留学指导）
footer.footer           531px   蓝→绿渐变，地址/邮箱/版权 + 技术支持：CQUPTHUB工作室
```

**模块语法**（从 HTML 里逐字抄下来的结构）：

```html
<div class="module-header">
  <h3><i class="module-icon">…</i> 综合新闻</h3>
  <a href="…" class="more-link">更多 ></a>
</div>
<div class="module-content"> … </div>
```

五处一模一样。**这是全站最有价值的一条**：它意味着"新增一个栏目 = 复制 4 行 HTML + 复用已有 CSS"。

对应到我们：Astro 里应该有一个 `Section.astro`（接 `title` / `headingId` / `moreHref` / `children`），现在我们的六个板块是手写六遍 `<section class="border-border border-b pt-12 pb-…">` + `<h2>`。见计划 P1-3。

## 3. 设计语言：三色漂移

| 色 | 值 | 出现形式 | 实测用途 |
|---|---|---|---|
| 蓝 | `#0055A4` | `--primary-color` / `--color-primary-start` | 32 处文本色、链接、模块图标 |
| 青 | `#2E97D8` | `--color-primary-end` | 1 处（渐变的另一端） |
| 绿 | `#006633` | **硬编码**在 `.header` / `.footer` 的渐变里 | 品牌色带 |
| 紫 | `#6c5ce7` → `#a29bfe` | `--secondary-color`，但**变量 0 次使用**，渐变在 `.date-tag` 里硬编码 2 次 | 日期徽章、"招生资讯"卡片微渐变 |

**结论**：视觉上的主色是"蓝→绿渐变"，但 token 台账里的主色只有蓝；紫色是第三个色系，只活在日期徽章里。

### 3.1 token 台账的三类问题（逐条可核对）

| 问题 | 明细 |
|---|---|
| **只引用不定义**（14 处声明失效） | `--transition`（5 次）、`--bg-white`（3 次）、`--bg-light`（2 次）、`--border-light`（2 次）、`--transition-long`（2 次） |
| **同义重复** | `--primary-color` 与 `--color-primary-start` 同值 `#0055A4`；`--color-white` 与 `--text-white`/白值并存 |
| **关键值硬编码** | 页头页脚渐变 `#003377→#006633`、日期徽章渐变 `#6c5ce7→#a29bfe`、4 组卡片微渐变（`rgba(108,92,231,.1)` 等） |

> **失效声明的实际后果**：`transition: var(--transition)` 解析为空 → 该属性整条失效 → 元素没有过渡。**这类 bug 不会报错，只会"看起来不够顺"**。

### 3.2 值得抄的两个细节

1. **日期徽章**：`20px 日 + 12px 月 + 10px 周` 三层塞进 60×72 的圆角块，紫色渐变 + `0 2px 8px rgba(0,0,0,.2)`。列表里 20 条通知，靠这个块就能一眼扫出"哪条是新的"。
2. **banner 压字**：`linear-gradient(to top, rgba(0,0,0,.8), transparent)` 从左下往上压，白字直接盖在图上看不清的位置。

## 5. 可借鉴清单

### 5.1 模块组件化 ★★★

**做法**：一个 `Section` 组件承接"板块标题 + 英文标签 + 更多链接 + 分隔线 + 垂直节奏"。

我们现状：六个板块各写一遍——

```html
<section class="border-border border-b pt-12 pb-6" id="featured"> … </section>
```

建议（Astro）：

```astro
<Section id="featured" index="02" zh="精选案例" en="SELECTED CASES" more={{ href: "/case-studies/", label: "全部案例" }}>
  …
</Section>
```

收益：**板块编号、双语标签、`更多 →`、分隔线、间距一次定义**；新增板块零成本；也顺带解决拆解 02 §8.1 的双语标题需求。

### 5.2 日期徽章 ★★

我们的案例卡有 `pubDatetime`（如 `2026-09-28`），但只是 12px 灰字。可改为紧凑的"日/月"块（`20px 日 + 12px 月`，1px 描边不填色，符合我们的纸面风格），用于列表视图。

### 5.3 "更多 >" 的显式出口 ★★

每个模块右上角一个"更多 >"，告诉读者"这里还有更多"。我们的 5 个板块**都有**出口按钮，但位置一律在板块底部、文案各写各的（`全部案例` / `全部报告` / `全部拆解` / `开始阅读与复算` / `打开工具箱`）。建议：**主出口上提到板块标题右侧**（`全部 →`），底部只留"次级动作"。

### 5.4 卡片的"微渐变底" ★

`linear-gradient(135deg, rgba(108,92,231,.1), transparent)` 这类 5%–10% 透明度的色底，让白卡有极淡的色相。我们可以用栏目的 `--section-*` 色做同款（`color-mix(in srgb, var(--section-case) 6%, transparent)`）。

## 6. 明确不借鉴

- **2.1 MB 的 banner**：我们要上首屏图，必须是 webp + 多档 + `fetchpriority`，且压到 200 KB 以内。
- **横向溢出**：我们已有 `overflow-x` 门禁与移动端 390 实测，不回退。
- **硬编码渐变 + 死 token 混用**：我们的下一步是"全部进 token + 禁止裸 hex"，方向相反。
- **154 处过渡**：收敛为 120ms / 200ms 两档。
