# 2 分钟 demo 讲稿（面试现场 / 录屏两用）

对象：www.yuhailinlxy.com + toolbox.yuhailinlxy.com。`[mm:ss]` 为讲述节奏，不是幻灯片切换。

## 开场定位 [0:00-0:20]
打开首页：「这是我的作品集工程 pm-forge——不是页面集合，是一条『数字可复算、结论可溯源、质量有门禁』的流水线，对应 AI 产品经理面试的五个考点。」

## 数据分析 [0:20-0:45]
进「数据」→ UserBehavior 报告：「同一份数据 SQL 和 pandas 双实现，每个数字带口径定义——先定口径，再看结论。」

## 现场复算 [0:45-1:20]（演示高潮）
进「数据故事」→ 滚到底部查询框 → 点「加载引擎」→ 任选类目跑一次查询：「这个数字是浏览器本地 DuckDB 现算的——您可以改条件自己算，我的数据不怕被复算。」
（备用口径：首次加载约 10 秒，正好看得到懒加载边界——首屏零重资源是 Playwright 门禁守着的。）

## AI 评测 [1:20-1:45]
开「契约修复报告」或 toolbox：「我给 AI 工具建了 66 例评测集和回归基线——基线抓到 4 例违例、修复、复测全过。AI 落地不是调 prompt，是建测量。」

## 失败案例收束 [1:45-2:00]
开拆解：「30 条实测里 5 条失败逐条可查——失败案例和成功案例同等呈现，这是模型评估的诚实口径。」

## 录屏前检查清单（脱敏纪律，逐项勾）
- [ ] 关闭/裁切一切账号信息（登录态、邮箱、通知中心）
- [ ] 浏览器书签栏、下载列表、历史记录清理
- [ ] toolbox 用演示模式（MOCK_LLM=1）除非明确要展示 live API
- [ ] 1080p 起、浏览器 100% 缩放、无个人输入法皮肤残留
- [ ] 数据故事页演示用预置问，查询框不输入任何真实个人信息

## 常见追问 → 弹药指向
- 「数字怎么保证对？」→ 三端交叉验证 + 构建期门禁（analysis/src/pmforge_analysis/check_story_presets.py、site/scripts/check-dissections.mjs）
- 「AI 代跑占比？怎么保证不是 AI 编的？」→ 章程 v2.1 执行授权修订款（人工节奏代跑 + 措辞终审留痕）+ 30 条原始记录 JSON 逐条可查
- 「为什么把失败案例放作品集里？」→ spec 验收②：失败案例库 ≥5 是硬性验收项，不是装饰
- 「这项目多少是你写的？」→ 指公开仓库 commit 留痕与审查报告：AI 协作流程本身就是作品集主张
