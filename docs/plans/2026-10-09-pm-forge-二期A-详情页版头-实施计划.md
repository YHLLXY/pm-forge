## Task 4：新增 h1 结构与标题层级门禁

**Files**：Create `site/scripts/check-headings.mjs`；Modify `site/package.json`

**Interfaces**：
- Consumes：`site/dist/**/*.html`
- Produces：退出码 0 = 通过；非 0 并打印违规清单

**为什么需要**：把 `<h1>` 从四个页面搬进一个共享组件，最大的回归风险是**同一页出现两个 h1**（例如未来某个页面既用 `EntryHeader` 又保留原 h1）。Lighthouse 的 a11y 审计**没有「h1 唯一性」这一项**，所以现有的 100 分挡不住这个错误。

- [ ] **Step 1：写脚本**

```js
// site/scripts/check-headings.mjs —— 每个 dist HTML 恰好一个 h1；标题层级不跳级
import { readdirSync, readFileSync, statSync } from "node:fs";
import { join, relative } from "node:path";
import { fileURLToPath } from "node:url";

const DIST = fileURLToPath(new URL("../dist/", import.meta.url));
const problems = [];

function* walk(dir) {
  for (const name of readdirSync(dir)) {
    const p = join(dir, name);
    if (statSync(p).isDirectory()) yield* walk(p);
    else yield p;
  }
}

for (const p of walk(DIST)) {
  if (!p.endsWith(".html")) continue;
  const rel = relative(DIST, p).replaceAll("\\", "/");
  const html = readFileSync(p, "utf8");
  const levels = [...html.matchAll(/<h([1-6])[\s>]/g)].map(m => Number(m[1]));
  const h1 = levels.filter(l => l === 1).length;
  if (h1 !== 1) problems.push(`${rel}: h1 数量 = ${h1}（必须恰好 1）`);
  let prev = 0;
  for (const lv of levels) {
    if (prev && lv > prev + 1) problems.push(`${rel}: 标题从 h${prev} 跳到 h${lv}`);
    prev = lv;
  }
}

if (problems.length) {
  console.error("✗ 标题结构检查失败：");
  for (const m of problems) console.error("  " + m);
  process.exit(1);
}
console.log("✓ 标题结构检查通过（每页恰好一个 h1，无跳级）");
```

> 已知会被这条规则打到的地方：`site/src/pages/dissections/[slug]/index.astro` 里正文之后直接是 `<h2>`，中间没有 h1 跳级问题；但如果某个页面的正文首个标题就是 `<h3>`（`app-prose` 里可能出现），脚本会报出来——**报出来先判断是不是真问题**，不要为了过门禁把 markdown 标题改乱。
