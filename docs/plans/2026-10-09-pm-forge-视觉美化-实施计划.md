## Global Constraints（沿用 spec）
- 国内红线：零第三方运行时请求、无 Google Fonts/CDN；新增依赖先验 npmmirror 在架性。
- 性能红线：Lighthouse 移动端四类 ≥90（当前多页 100）。
- a11y：明暗双主题对比度 ≥4.5:1（浅色档取 700 级，沿用 A1 先例）。
- 门禁不可破：`check-case-studies / check-dissections / check-links / validate-rss / check-ld / check-story-budget`。
- git：显式 `git add <文件>`，禁 `add -A`；`feat:/fix:/docs:/style:` 前缀；commit 必 push（本轮 push 到 `visual-refresh` 分支）。

## Task 4：封面生成脚本（构建期 SVG，零运行时依赖）

**Files**：新增 `site/scripts/build-covers.mjs`；`site/package.json`（build 首步）；`site/public/assets/covers/`（产物 gitignore 或入库待定）

- 读取 4 个集合的 frontmatter，为每个条目生成确定性 SVG 封面到 `public/assets/covers/<collection>-<id>.svg`
- 封面元素：板块眉标（英文，衬线字母间距）、日期、**真实数据的核心数字 + 标签**、极淡点阵纹理、板块识别色竖条
- **诚实原则：不放"假装是数据"的假图表**。条形装饰只在有真实序列时使用（如拆解记录的判定分布）；其余用中性几何构成
- 幂等：同输入两次生成零 diff

**验收**：生成 N 张 SVG；连续两次运行 `git status` 零 diff；XML 合法（复用 `fast-xml-parser` 校验）。
