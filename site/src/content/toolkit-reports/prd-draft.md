# PRD：月度消费报告导出 PDF

## 一、背景与目标

**为什么做**
- 现状问题：用户月底查看月度消费报告后，只能通过截图保存/分享，截图排版差（长图被裁切、分多张）、信息不全（分类占比、收支结构、环比数据往往不在首屏），接收方（家人）无法看到完整收支结构。
- 机会：导出为标准 PDF 后，用户可一次性保存完整报告并直接转发给家人，提升报告分享率与记账工具的"被看见"价值，间接拉动记账留存。

**要达成什么**
- 北极星指标：月度报告导出成功率 = 导出成功次数 / 导出触发次数（口径：同一用户同一次点击"导出"计 1 次触发，生成并成功保存/转发文件计 1 次成功；按自然周统计，用户不去重，按次数）。
- 护栏指标 1：导出流程平均耗时 = 从点击导出到文件可用的总时长（口径：P50/P90，单位秒，按自然周统计全部导出事件）。
- 护栏指标 2：导出功能崩溃率 = 导出流程中触发前端异常的次数 / 导出触发次数（口径：按自然周统计，含小程序白屏、Canvas 渲染失败、内存溢出）。
- 护栏指标 3：报告页跳出率 = 进入月度报告页后未停留满 3 秒即离开的会话数 / 进入报告页的会话数（口径：按自然周统计，用于监控导出入口是否干扰原有浏览体验）。

【待补充：当前截图分享的占比基线、报告页 UV、目标提升幅度由谁确认——需与数据/增长负责人确认】

## 二、用户与场景

- 目标用户：使用随手记账微信小程序的**大学生用户**，有月度复盘习惯，消费来源包含生活费、兼职、奖助学金等，需要向家人（父母）说明钱花在哪。
- 核心场景一句话：**大学生在月底打开月度消费报告，希望把完整收支结构导出成一份排版整齐的 PDF，保存到本地或直接发给父母查看。**

【待补充：用户是否有"发给朋友/社团/自己做年度汇总"等次要分享场景，是否纳入本期——需与产品负责人确认】

## 四、流程与交互

**主流程（分步）**
1. 用户在首页/账单页进入「月度消费报告」页。
2. 报告页渲染完成后，展示「导出 PDF」入口（F1）。
3. 用户点击导出 → 前端进入加载态（F3）。
4. 前端基于当前报告数据，在本地生成 PDF（小程序环境，无后端图片服务，采用前端绘制方案：Canvas 绘制 → 导出图片 → 合成 PDF / 或纯前端 PDF 库生成。【待补充：具体技术方案选型由前端负责人确认】）。
5. 生成成功后，展示预览或直接给出「保存到手机」「转发给好友」两个动作（F4）。
6. 用户完成保存/转发，流程结束，记录埋点。

**关键页面说明**
- 月度报告页：保留原有浏览体验，导出入口为新增次要动作，不遮挡核心数据。
- 导出中态：全屏或半屏 loading，含进度提示与取消能力（若技术可行）。
- 导出结果态：成功（预览缩略图 + 保存 / 转发按钮）、失败（原因文案 + 重试）。

**异常路径**
- 空态：该月无数据 → 提示并引导记账（F5）。
- 失败：生成的 PDF 为空/渲染异常/内存不足/保存失败 → 提示具体原因，提供"重试"，并记录埋点。
- 权限/环境不足：用户拒绝保存权限、微信版本不支持文件转发能力 → 降级为"生成图片长图"或提示升级微信。【待补充：是否接受降级为长图方案——需与产品负责人确认】
- 弱网：导出本身为前端生成，弱网影响主要在转发/上传环节 → 提示网络异常并允许重试。

【待补充：超长明细（如单月几百笔）时是否分页、每页条数上限——需与设计/前端确认】

## 五、非功能需求

- 性能：P90 端到端导出耗时目标 ≤ 【待补充：目标秒数，需与前端确认可行值】；生成过程不阻塞页面主线程滚动（若阻塞，需给明确 loading）。
- 兼容：覆盖主流微信版本与机型；低端机内存受限时需有降级或失败兜底。具体支持的微信基础库版本下限【待补充：由前端负责人确认】。
- 合规：PDF 内含用户消费数据，属个人隐私信息，不得在未经用户操作的情况下自动外发；分享行为须由用户主动点击触发；遵守《个人信息保护法》相关要求。【待补充：是否需要隐私协议提示——需与法务/合规确认】。
- 数据埋点（事件名 + 参数 + 触发时机）：
  - `export_pdf_clicked`：参数 `{ report_month, entry_from, has_data }`，触发时机：用户点击"导出 PDF"按钮瞬间。
  - `export_pdf_succeeded`：参数 `{ report_month, duration_ms, file_size_kb }`，触发时机：PDF 生成成功且可保存/转发时。
  - `export_pdf_failed`：参数 `{ report_month, fail_reason, duration_ms }`，触发时机：导出流程任一环节失败时（fail_reason 枚举：render_error / memory_limit / save_denied / unsupported_env / network）。
  - `export_pdf_shared`：参数 `{ report_month, share_channel }`，触发时机：用户成功调起转发并发送后。
  - `export_pdf_saved`：参数 `{ report_month }`，触发时机：用户成功保存文件到本机后。
  - `export_pdf_retried`：参数 `{ report_month, retry_count }`，触发时机：用户在失败态点击"重试"时。

## 六、风险与开放问题

| 风险/问题 | 影响 | 当前判断 | 需要谁拍板 |
|---|---|---|---|
| 无后端图片服务，PDF 需纯前端生成 | 生成质量、耗时、机型兼容性不保证 | 倾向前端 Canvas + PDF 库方案，需先做可行性验证 | 前端负责人 |
